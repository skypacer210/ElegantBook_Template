# 优雅小书 (Lab Book)

本项目旨在**聚集学术相关的规范化管理与格式化输出**，为科研工作者和学生提供优雅、标准且高效的学术写作体验。

## 核心目标与特性

- **学术规范管理**：涵盖日常实验记录（Lab Book）、文献整理、以及学术论文写作过程中的标准化建议与管理方案。
- **高质量格式化输出**：主要基于 LaTeX 等排版工具，提供标准化、开箱即用的文档模板与排版方案，确保输出结果符合学术界严苛的排版要求。
- **LaTeX 语法与技巧沉淀**：记录并总结学术写作中高频使用的 LaTeX 语法、公式排版、图表处理宏包及常见报错解决方案，方便随时查阅与复用。
